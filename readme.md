# Blog Platform API

Вариант 2: блог-платформа.

API позволяет работать со статьями, комментариями, категориями и лайками.
Фреймворк: FastAPI.
База данных: SQLite через SQLModel.

Функционал:

* регистрация пользователя;
* вход через BasicAuth;
* просмотр статей;
* создание, редактирование и удаление статей;
* работа с категориями;
* создание, редактирование и удаление комментариев;
* лайки статей;
* фильтрация статей по категории и статусу;
* пагинация статей;
* сортировка по дате и популярности.

Используемые технологии:

* Python 3;
* FastAPI;
* SQLModel;
* SQLite;
* Pydantic.

Установка:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
fastapi dev main.py
```

После запуска документация доступна по адресу:

```txt
http://127.0.0.1:8000/docs
```

Стартовые пользователи:

```txt
reader / 123
author / 123
moderator / 123
```

Роли пользователей:

Читатель:

* может читать опубликованные статьи;
* может писать комментарии;
* может ставить лайки.

Автор:

* может читать опубликованные статьи;
* может создавать свои статьи;
* может редактировать и удалять свои статьи;
* может видеть свои черновики.

Модератор:

* может управлять всеми статьями;
* может управлять всеми комментариями;
* может управлять категориями.

Основные эндпоинты:

```txt
POST /register/
GET /login/
```

Категории:

```txt
POST /api/categories
GET /api/categories
GET /api/categories/{category_id}
PUT /api/categories/{category_id}
DELETE /api/categories/{category_id}
```

Статьи:

```txt
POST /api/posts
GET /api/posts
GET /api/posts/{post_id}
PUT /api/posts/{post_id}
DELETE /api/posts/{post_id}
```

Комментарии:

```txt
POST /api/comments
GET /api/comments
GET /api/comments/{comment_id}
PUT /api/comments/{comment_id}
DELETE /api/comments/{comment_id}
```

Лайки:

```txt
POST /api/posts/{post_id}/likes
DELETE /api/posts/{post_id}/likes
GET /api/posts/{post_id}/likes
```

Валидация:

* логин не может быть пустым;
* пароль не может быть пустым;
* название категории не может быть пустым;
* заголовок статьи не может быть пустым;
* текст статьи не может быть пустым;
* комментарий не может быть пустым;
* id категории и статьи должны быть больше 0;
* статус статьи может быть только draft или published.

Ошибки:

* 400 — ошибка валидации;
* 401 — ошибка входа;
* 403 — нет прав;
* 404 — объект не найден;
* 409 — конфликт данных.
